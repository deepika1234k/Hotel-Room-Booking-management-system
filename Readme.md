# 🏨 Hotel Room Booking Management System

## 📌 Project Overview

The **Hotel Room Booking Management System** is a web-based application developed to simplify hotel room booking and management activities.

The system provides an easy-to-use interface for managing hotel operations. It aims to reduce manual work, maintain booking information, and make hotel room management more efficient.

This project is developed using Java, JSP, Servlets, HTML, CSS, JavaScript, and MySQL.

## 🎯 Objectives

- To develop a simple and user-friendly hotel management application.
- To provide administrator login functionality.
- To manage hotel room booking information.
- To store and retrieve information using a MySQL database.
- To reduce manual work and improve data management.

## ✨ Features

- **Admin Login:** Provides administrator authentication.
- **Room Management:** Supports hotel room management.
- **Booking Management:** Helps manage room booking information.
- **Database Connectivity:** Stores application data in MySQL.
- **User Interface:** Provides a simple and easy-to-use web interface.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have installed:

- JDK 17 or above
- Apache Tomcat 10 or compatible Jakarta EE 10 server
- MySQL Server
- MySQL Workbench
- Visual Studio Code or Eclipse
- Maven

### Step 1: Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/deepika1234k/Hotel-Room-Booking-management-system.git
```

### Step 2: Open the Project

Open the downloaded project folder in Visual Studio Code or Eclipse.

### Step 3: Configure MySQL

1. Start your MySQL server.
2. Create the required database.
3. Configure your database connection details in the project's database connection file.
4. Make sure the database username and password are correct.

### Step 4: Build the Project

Open the terminal inside the project directory and execute:

```bash
mvn clean package
```

### Step 5: Run the Application

1. Deploy the generated WAR file to Apache Tomcat.
2. Start the Tomcat server.
3. Open your browser.
4. Access the application using:

```text
http://localhost:8080/HotelBookingJSP/
```
